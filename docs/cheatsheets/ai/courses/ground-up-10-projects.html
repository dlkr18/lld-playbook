Projects that prove it // AI from the ground up · Part 10

Reading gets you through interviews' first round; artifacts get offers. Each project below is small, and together they cover every AI line in the job post.

1 Foundation3 Core1 Advanced

01 — Project 1: micrograd and an MNIST MLP

Foundation

Covers Parts 0–2. Autograd from scratch, then a tensor-level MLP with your own training loop. Proof you understand backprop, losses and optimizers, not just APIs.

02 — Project 2: a GPT from scratch

Core

Covers Parts 3–4. Train a ~10M parameter GPT on Tiny Shakespeare or a code corpus. Add KV cache, temperature/top-p sampling, and a parameter-count check against your formula. Write up loss curves and samples.

03 — Project 3: QLoRA fine-tune with real evaluation

Core

Covers Parts 5–6. Narrow task (text-to-SQL with execution accuracy is ideal: automatic, objective metric). Base vs tuned table, forgetting check, adapter and model card on the Hub.

04 — Project 4: distill and serve fast

Core

Covers Part 8. Generate training data with a large model, distill into a ~1.5B model, AWQ-quantize, serve with vLLM. Table of accuracy, TTFT, TPOT and throughput across variants.

05 — Project 5: ship it

Advanced

Covers Parts 7–9 and the "shipped to real users" line. Wrap the model in a product: retrieval over a real dataset if useful, streaming API, simple web UI, feedback logging, deployed on a cloud GPU with Docker. Get 20+ real users and publish the repo with an architecture diagram and a blog post on what broke.

Your one-breath interview pitch: "I QLoRA-tuned a 1.5B model that beats the base by X points on Y, distilled from a frontier model, served it with vLLM at Z tokens/s for N real users."
